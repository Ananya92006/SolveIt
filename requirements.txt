# ==============================================================================

# SolveIt is a full-stack algorithmic coding platform built with Node.js/Express,
# React 19/Vite, MongoDB, Redis, Monaco Editor, Judge0 CE, and Cloudinary.
#
# JavaScript/Node.js dependencies are managed via npm / package.json.
# This file provides a unified overview of all system prerequisites, runtime
# dependencies, and external cloud services required to run SolveIt.
# ==============================================================================

# ------------------------------------------------------------------------------
# 1. System & Runtime Prerequisites
# ------------------------------------------------------------------------------
# Node.js: >= 18.0.0 (LTS recommended, e.g., v18.x or v20.x or v22.x)
# npm: >= 9.0.0 (bundled with Node.js)
# Database: MongoDB >= 6.0 (Local instance or MongoDB Atlas Cloud URI)
# Cache / Broker: Redis >= 6.0 (Local redis-server or Redis Cloud / Upstash)

# ------------------------------------------------------------------------------
# 5. External API Services & Credentials
# Configure these in Backend/.env (see Backend/.env.example)
# ------------------------------------------------------------------------------
# Judge0 CE (RapidAPI):
#   - Service: Remote sandboxed code execution engine for C++, Java, JavaScript
#   - Provider: https://rapidapi.com/judge0-official/api/judge0-ce
#   - Env Var: JUDGE0_KEY
#
# MongoDB:
#   - Service: Document database for users, problems, submissions, discussions
#   - Provider: https://www.mongodb.com/atlas
#   - Env Var: DB_CONNECT_STRING
#
# Redis:
#   - Service: High-speed caching & user session store
#   - Provider: https://redis.io or https://upstash.com
#   - Env Var: REDIS_PASS
#
# Cloudinary:
#   - Service: Video editorial upload and video streaming
#   - Provider: https://cloudinary.com
#   - Env Vars: CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY, CLOUDINARY_API_SECRET
#
# Google Gemini API (Optional):
#   - Service: AI hint generation and algorithm coaching
#   - Provider: https://aistudio.google.com
#   - Env Var: GEMINI_KEY
